FAQ

Common questions.

Do you take on existing projects?

Yes. Bug fixes, code review, refactors, and performance work are all aimed at projects that are already running. We can work inside your current codebase rather than asking you to start over.

Can you match our existing codebase and conventions?

We build to fit your project. Tell us the structure, naming, and patterns you already use and we'll follow them, so new code looks like it belongs next to the old.

How is work handed over?

Every task is scoped, built, and reviewed before it comes back to you. You get the code plus notes on what changed, how it works, and anything you should know about it.

What languages do you work in?

Our core is Lua/Luau for Roblox, backed by general purpose programming in Python, C++, and other high-level languages for tools, pipelines, bots, and websites.

How does a project get scoped?

You tell us what you need, our management scopes it out with you, and the rate is agreed before any work begins. Nothing starts until the scope and rate are settled.
